# Coding Challenge 1: Climate Change in Boulder
Higher highs, lower lows, storms, and smoke -- we're all feeling the effects of climate change. In this workflow, you will take a look at trends in temperature over time in Boulder, Colorado.

## Challenge overview
To complete this assignment on GitHub Codespaces:
    1. Fork the repository and go to your version of the repo.
    2. Open the notebooks in GitHub Codespaces by clicking on the Code button, then selecting the Codespaces tab, then selecting "Create codespace on main."
    3. Wait for the Codespace to load. It can take a few minutes for the Codespace to load for the first time. Be patient! It doesn't make it go faster to try again. You can find out more about all your Codespaces at https://www.github.com/codespaces. If you are using this repository through GitHub Education/Pro, you shouldn't run out of Codespace minutes, but you can run out of storage space if you have too many Codespaces open or download too much data.
    4. Complete the notebooks in the assignment.
    5. Commit and sync your changes in Codespaces so that they show up in your repository.


Once you have finished the assignment notebookds:
    1. Create a new notebook in your portfolio repository.
    2. Concisely duplicate your analysis for a location and time period of your choosing. Only include the code needed to generate the main plot you make. You do not need to include all the code from the original assignment notebooks if it isn't relevant.
    3. Write a portfolio post explaining your research questions, methods, results, and interpretation. Add your interactive plot to the post, with a title and description of the plot. 
    4. Upload the post to your data science portfolio webpage to show off your work!

The following code may help you export your analysis:

```bash
jupyter nbconvert <your-notebook-name>.ipynb --to markdown --no-input
```

You can run this code within your notebook as a `%%bash` cell, or in the terminal.
